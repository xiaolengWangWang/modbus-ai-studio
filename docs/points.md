# 点表格式

点表是设备的地址表，每一行说明一个地址是什么、怎么从寄存器里的原始值换算成工程值、能不能写。为什么需要点表，见 [使用说明 · 点表与工程值](guide.md#点表与工程值)。

点表是 CSV 文件，用 Excel 编辑后“另存为 CSV”即可，UTF-8（带不带 BOM 都行）和 GBK 编码都能识别。导入：“读取 → 导入点表 CSV”。

## 例子

```csv
地址,名称,类型,字节序,倍率,单位,读写,最小,最大,枚举,长度
40347,温差设定,FLOAT32,CDAB,1,℃,RW,5,25,,
40005,二次温差,INT16,,0.1,℃,R,,,,
40019,补水泵状态,UINT16,,,,,,,0=停止;1=运行,
40701,累计电能,UINT64,CDAB,0.001,kWh,R,,,,
30001,电压,FLOAT,ABCD,,V,,,,,
40901,设备型号,STRING,,,,,,,,16
```

完整的例子是换热站模板 [assets/examples/heat-station-points.csv](../assets/examples/heat-station-points.csv)，与“读取 → 打开换热站示例”用的点表完全一致。

## 列

第一行是表头，按列名识别，列的顺序随意，不用的列可以不写。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 地址 | 是 | 40001 起是保持寄存器，30001 起是输入寄存器；也可以写 4x0347、3x0001、400001 起的 6 位写法。其他数字（如 346）按保持寄存器的协议地址（0 起始）处理。只支持保持寄存器和输入寄存器 |
| 名称 | 是 | |
| 类型 | 是 | 见 [类型](#类型) |
| 字节序 | 否 | 见 [字节序](#字节序)。不填为标准大端（AB、ABCD、ABCDEFGH） |
| 倍率 | 否 | 工程值 = 原始值 × 倍率，例如 0.1、0.01。不填为 1，不能为 0 |
| 单位 | 否 | 显示在值的右边 |
| 读写 | 否 | 含 W 或“写”（RW、W、读写）表示可写，否则只读。只有保持寄存器能写，字符串点只读 |
| 最小、最大 | 否 | 可写点允许的工程值范围，两个都填才检查，超出范围不让写 |
| 枚举 | 否 | 状态值的含义，写成 `0=停止;1=运行`，中文冒号、分号也行。显示为“0 停止” |
| 长度 | STRING 必填 | 字符数，1–240 |

## 类型

| 类型 | 寄存器数 | 也可以写 | 取值范围 |
| --- | --- | --- | --- |
| INT16 | 1 | INT、SHORT | -32768 – 32767 |
| UINT16 | 1 | UINT、WORD | 0 – 65535 |
| INT32 | 2 | DINT、LONG | -2147483648 – 2147483647 |
| UINT32 | 2 | UDINT、DWORD | 0 – 4294967295 |
| FLOAT32 | 2 | FLOAT、REAL | 单精度浮点，约 7 位有效数字 |
| INT64 | 4 | LINT | -9223372036854775808 – 9223372036854775807 |
| UINT64 | 4 | ULINT、LWORD、QWORD | 0 – 18446744073709551615 |
| FLOAT64 | 4 | DOUBLE、LREAL | 双精度浮点，约 15 位有效数字 |
| STRING | 长度 ÷ 2 | STR、CHAR | 每个寄存器 2 个字符，遇到 0 结束 |

占多个寄存器的点，后面几个地址不能再定义别的点，导入时会报“被前面的多寄存器点占用”。

INT64、UINT64 不换算（倍率 1）时按整数精确显示和写入，超过 2^53（约 9×10^15）也不会丢最后几位。

## 字节序

字母表示数值按大端排列时的字节，A 是最高字节。字节序说的是这些字节在寄存器里怎么摆。以 FLOAT32 的 15.0（大端字节 41 70 00 00）为例：

| 字节序 | 寄存器 1 | 寄存器 2 | 设备手册里的常见说法 |
| --- | --- | --- | --- |
| ABCD | 0x4170 | 0x0000 | 大端、高字在前、Big-endian |
| CDAB | 0x0000 | 0x4170 | 低字在前、字交换、Word swap（很多 PLC 和仪表用这种） |
| BADC | 0x7041 | 0x0000 | 字节交换、Byte swap |
| DCBA | 0x0000 | 0x7041 | 小端、Little-endian |

64 位类型有对应的四种：

| 32 位 | 64 位 | 含义 |
| --- | --- | --- |
| ABCD | ABCDEFGH | 标准大端 |
| CDAB | GHEFCDAB | 低字在前 |
| BADC | BADCFEHG | 字内字节交换 |
| DCBA | HGFEDCBA | 完全小端 |

设备手册常只写 32 位的字节序。64 位点直接填 ABCD、CDAB、BADC、DCBA 也可以，会换成同一行的 64 位写法。

16 位类型只有 AB（标准）和 BA（字节交换）两种；STRING 的 AB 表示每个寄存器高字节在前，BA 表示每个寄存器内两个字符对调。

**不知道字节序时**：先按 ABCD 导入，在读取窗口里单击这个点的第一个寄存器，右下角的解析会列出四种字节序下的值，并标出哪些合理；FLOAT32 / FLOAT64 显示明显不合理（灰色）时，自动分析也会直接建议改用哪种。

## 导入报错

导入时逐行检查，出错会指出第几行、哪一列，例如：

| 提示 | 原因 |
| --- | --- |
| 表头缺少“地址”列 | 第一行要有地址、名称、类型三列，列名要一字不差 |
| 类型“BCD”不认识 | 类型不在上面的表里 |
| FLOAT32 不能用字节序 AB | 32 位类型要用四个字母的字节序 |
| 地址 40002 与前面的点重复，或被前面的多寄存器点（32 / 64 位、字符串）占用 | 40001 是 32 位点，已经占了 40002 |
| 40001 占用 2 个寄存器，其中 40002 已经是“…” | 同上，只是 40002 那一行写在前面 |
| 地址 10001 是 1x 区 | 点表只支持保持寄存器（4x）和输入寄存器（3x） |
| STRING 要在“长度”列填字符数（1–240） | 字符串点缺长度 |
| 枚举“停止”应写成 0=停止;1=运行 | 枚举格式不对 |
