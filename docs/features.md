# 功能说明

Modbus AI Studio 面向工业现场调试：界面参考 Modbus Poll，出错时自动分析原因并给出一键处理。下面按功能介绍，标题后的版本号是该功能首次出现的版本。

## 调试功能（0.4.0）

- **多开**：“文件 → 新建窗口”（⌘N / Ctrl+N）或连接栏右侧按钮打开新的主窗口，每个主窗口有独立的连接、读取窗口和通信报文，可同时调试多台设备；新窗口沿用当前的协议和目标。同一个串口同一时刻只能被一个窗口打开，会给出明确提示。关掉最后一个主窗口才退出。macOS 在访达里双击不会再启动第二个进程，需要第二个进程时用 `open -n "/Applications/Modbus AI Studio.app"`。
- **读取窗口**：主窗口启动时为空，读取窗口按需新建 / 关闭（⌘T），自动平铺；“读取 → 打开换热站示例”一次打开三个示例窗口并连接内置模拟器。每个窗口有自己的读取定义：Slave ID、功能码 01–04、起始地址（346、0x015A、40347、4x0347，有歧义时列出全部解释）、数量、扫描周期、显示格式（点表工程值、Signed、Unsigned、Hex、Binary、INT32 / UINT32 / FLOAT32 + 四种字节序）、每列行数。可单独暂停，刚变化的值高亮，读取失败时保留上次的值并灰显。
- **Err ≠ 0 自动分析**：错误行下面给出原因和一键处理，例如晚到响应 → “超时改为 2000 ms”（立即生效，不用重连）；异常 02 → 逐个探测可读地址并一键改为可读范围；异常 01 → 改用 FC03 / FC04；异常 03 → 数量减半；Modbus TCP 一直无响应或收到非 MBAP 数据 → 识别协议后自动重连；FLOAT32 值不合理 → 建议正确的字节序。
- **寄存器解析**：单击任意值，右下角显示地址的各种写法、16 位有符号 / 无符号 / 二进制 / 字节交换，以及与下一个寄存器组成 32 位时四种字节序下的 FLOAT32 / INT32 / UINT32，并标出哪些合理。
- **报文监控**：通信报文每 100 ms 合并刷新一次，高频轮询时界面不卡；可按“仅错误”筛选、按字节查找、复制、保存为文本；单击一行自动暂停并逐字段解析（MBAP / 从站地址 / 功能码 / 地址 / 每个寄存器的值 / CRC 校验与正确值 / 异常码含义与建议）。
- **写入**：双击值打开写入。点表可写点按工程值写入并检查范围和字节序；其他保持寄存器按窗口显示格式写原始值（FC06 / FC16）；线圈写 ON / OFF（FC05 / FC15）。确认后都在 0 / 200 / 1000 ms 回读验证，未生效或被覆盖时可一键恢复原值。
- **自定义请求**（⌘R）：发送任意 PDU，自动加 MBAP 头或 CRC，预览完整报文，逐字段解析请求和响应，支持常用模板和循环发送，可调试 FC08、FC11、FC2B 等不常用功能码。
- **工作区**（⌘S / ⌘O）：连接参数、全部读取窗口和点表存成一个 JSON 文件，打开后不自动连接；空白页列出最近打开的 5 个工作区。
- **CSV 点表**（“读取 → 导入点表 CSV”）：每个主窗口各有一份点表，初始为空。第一行是表头，列顺序随意，地址、名称、类型必填：`地址,名称,类型,字节序,倍率,单位,读写,最小,最大,枚举,长度`（长度只有 STRING 要填）。地址支持 40347、4x0347、30001（输入寄存器）、346；类型也认 FLOAT / REAL / WORD / DINT 等写法；枚举写成 `0=停止;1=运行`；兼容 Excel 另存的 UTF-8 和 GBK。模板见 [assets/examples/heat-station-points.csv](../assets/examples/heat-station-points.csv)。
- **总线扫描**：“调试 → 扫描从站地址”逐个试 Slave 1–247（异常响应也算在线），只找到一台时一键改读取窗口的 Slave；“连接 → 扫描串口参数”依次试 8 种波特率 × 8N1 / 8E1 / 8O1 / 8N2，找到后填回连接栏。串口一直无响应、或同一连接上其他窗口正常只有本窗口超时时，自动分析里直接给出这两个按钮。
- **连接栏**：超时可在运行中修改；串口支持 8N1 / 8E1 / 8O1 / 8N2，串口列表自动刷新（插上 USB 转 485 几秒内出现）；按 1024 宽的工控机屏幕设计。

## 协议支持（0.5.0）

- **传输模式**：Modbus TCP、RTU over TCP、ASCII over TCP、RTU 串口、ASCII 串口。ASCII 帧（冒号、十六进制字符、LRC、CR LF）在通信报文里按字符显示并逐字段解析，LRC 错误和 CRC 错误一样读请求重试 1 次；ASCII 串口默认 7E1，也支持 7O1、7N2 和 8 位格式。“识别”会依次试 MBAP、RTU、ASCII 三种格式；“扫描串口参数”先试当前模式，再试另一种（RTU ⇄ ASCII）。
- **功能码**：01–06、15、16 结构化读写；07 读异常状态、08 诊断、11 / 12 通信事件、17 报告从站 ID、20 / 21 文件记录、22 掩码写、23 读写多个、24 FIFO、43 读设备标识（厂商、产品代码、版本、型号）都能在自定义请求里发送（有模板），请求和响应逐字段解析；RTU 下按规范计算帧长度，08、43 没有长度字段时按字符间隔分帧。功能码按规范用十进制写（FC16 = 0x10）。
- **诊断与异常**：“调试 → 读取诊断计数器”用 FC08 读出总线报文、通信错误（CRC / LRC）、异常、无响应等计数，可一键清零；异常码补上 08 Memory Parity Error；写入收到 05 Acknowledge 时按“已接受、处理中”继续回读，不再判为拒绝。
- **字符串**：读取窗口有 ASCII 显示格式（每个寄存器两个字符）；点表支持 STRING 类型（“长度”列填字符数，字节序 AB 或 BA）；寄存器解析给出从选中位置开始的字符串（两种字节序），设备型号、序列号一眼可见。
- **模拟器**：ASCII over TCP；应答 07、08（真实计数器）、11、17、22、23、43；0.7.0 起可注入断开连接类故障：连上就断、收到指定地址的请求就断、空闲超时断开。

## 报文记录（0.6.0）

- 连接期间的全部收发（含超时、异常、CRC / LRC 错误、晚到响应）自动存进本机 SQLite，每次连接一个会话；写入在后台批量进行，不拖慢通信，磁盘太慢时丢弃并在状态栏提示。保留 7 天，启动时清理。
- 数据库位置：macOS `~/Library/Application Support/ModbusAIStudio/packets.db`，Windows `%AppData%\ModbusAIStudio\packets.db`；所有窗口、所有进程共用（WAL 模式），可以直接用 SQLite 工具打开。表 `sessions`（每次连接）和 `packets`（每条收发，`status` / `protocol` 取值与界面一致）。
- “调试 → 历史报文”：选一次连接，查看它最后 5000 条记录，可按“仅错误”筛选、按字节查找、复制、保存，单击逐字段解析。
- 数据库打不开时照常运行，只是不记录。

## 断开与重连（0.7.0）

- TCP 类连接中途断开后自动重连（1 / 2 / 5 / 10 s 退避），重连期间停止轮询、不刷连接错误，重连后各读取窗口自动恢复；状态栏显示“n s 后第 m 次重连”和累计重连次数，重连失败时说明原因（连接被拒绝 = 服务没开或端口不对；连接超时 = 设备不在线或网络不通）。串口断开多半是 USB 转 485 被拔掉，不自动重连，提示插回后“重新连接”。
- 按断开发生的时机自动分析原因，在读取窗口里给出说明和一键处理：
  - **连上就断**（重连时先探测 300 ms，还没发请求就被关闭）：设备连接数已满（组态软件、别的上位机占着）、IP 白名单，或端口不是 Modbus 服务。
  - **发出某条请求后立刻断，每次都是**：一次正常响应都没有 → 多半是协议格式不对（Modbus TCP 设备收到 RTU / ASCII 帧会直接断开），给“识别协议”；其他请求正常 → 指出是哪条请求（Slave、功能码、地址），设备不接受这个站号、功能码或地址，给“暂停这条请求”，其他窗口照常工作。
  - **空闲一段时间后断**（请求前空闲 ≥ 10 s，同一请求在这条连接上成功过）：设备空闲超时，给“扫描周期改为 …”。
  - **用了一阵后随机断**：更像网络不稳或设备重启，给出本次断开次数和平均间隔。
- 断开和重连记进报文库 `events` 表（时间、原因、断开前最后一条请求），历史报文窗口的会话列表显示断开次数，选中后列出最近的断开和重连。网线被拔时 TCP 不会报错，表现为超时，走超时的分析。

## 只读模式（0.8.0）

在运行中的设备上排查问题时防止误写：“连接 → 只读模式（禁止写入）”，打开后状态栏显示“只读模式”。

- 写入对话框不能用（双击值会说明原因）；诊断计数器不能清零。
- 自定义请求只放行不改变设备状态的请求：读线圈 / 离散输入 / 保持寄存器 / 输入寄存器、读异常状态、通信事件、报告从站 ID、读文件记录、读 FIFO、读设备标识，以及 FC08 里只读的子功能（回送、读诊断寄存器、读计数器）；其他功能码，包括设备自定义的，一律拦下，不会出现在报文里。
- 设置随工作区保存，打开生产设备的工作区就是只读；“新窗口”继承当前窗口的设置。
